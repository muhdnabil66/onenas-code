### Pemasangan

```bash
# Menggunakan npm
npm i -g onenas-code

# Menggunakan bun
bun add -g onenas-code

# Menggunakan pnpm
pnpm add -g onenas-code

# Menggunakan yarn
yarn global add onenas-code
```

> [!TIP]
> Buang versi lama sebelum memasang versi baru.

### Aplikasi Desktop (BETA)
