Local workspace behavior

Install the signed Windows app, select Sign in with AtlasFlux AI, then choose Open Folder. ONeNas Code can work with files saved inside that workspace and run commands in its local terminal.

Privacy boundary

Raw local files, absolute paths and terminal output are not part of cloud history sync. Prompts, assistant replies and a sanitized timeline may be synced to your AtlasFlux account.

When AtlasFlux AI is unavailable

You can still inspect local files and existing local sessions. New AI runs are disabled; ONeNas Code does not bypass AtlasFlux by connecting directly to a model provider.

VS Code

Opening the same project folder lets ONeNas Code see files saved on disk. Unsaved editor buffers, selections and diagnostics are outside the first release.
