### Installation

```bash
# Using npm
npm i -g onenas-code

# Using bun
bun add -g onenas-code

# Using pnpm
pnpm add -g onenas-code

# Using yarn
yarn global add onenas-code
```

> [!TIP]
> Remove older versions before installing.
